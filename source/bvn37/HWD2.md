# HWD2 整合正式版

2026-11-13，用户在实体 PSP-2000 使用 HWD2 补丁、STDIO ONLY 模式后反馈游戏正常、此前发现的问题均已修复，并授权整合正式发布。完整包默认启用相同模式。实机反馈来自用户，未由本机直接操作实体 PSP；该反馈不扩大为完整战役或实体双机 WLAN 的验收。

此前报告的复现组合为市丸银对普通鸣人，玩家援助贾卡杰克，十三番队；报错文件为 NARUTO1.BVF、ERR=0、FIGHTER OPEN。NARUTO1 是普通鸣人家族内的一尾形态，入场时会预载。保留原预读取方式与同步 stdio 的对照入口，但正式默认采用已验证同步模式；造成先前错误的具体底层条件没有被单独隔离归因。

市丸银原待机 12 相位中 9 个被导出为透明。本版从固定原始 SWF 恢复对应有效放置，仅替换这 9 个空白视觉姿态，保留原先显示正常的 3 个姿态及所有其他动作、攻击、碰撞、事件、命令、片段时序。证据和提取图形在 repair/gin_idle/。

保留细分的资源读取/校验步骤、短读信息及失败文件 CRC 复读检查。正常战斗帧不写日志。若发生新错误，BVN_DIAG.LOG 可记录读取步骤、期望/实际字节、EOF/ferror、文件长度、元数据签名和失败时内存；每次启动覆盖日志。

FILE CRC OK 表示清理本轮资源后复读的失败文件与固定发行资源一致；FILE CRC DIFFERENT 表示字节或长度不一致；FILE CHECK FAILED 表示复读未完成。校验本身不单独证明问题来自硬件或代码。

正式包包含完整游戏及 BVN_SYNC.IO 默认读取标记。游戏程序与已验证补丁一致，只恢复正式 PSP 菜单标题。构建从完整安装包校验数据并编译程序，不再需要用户单独下载或安装补丁。
